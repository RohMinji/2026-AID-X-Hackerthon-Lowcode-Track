채점 에이전트가 커밋한 결과를 확인하고, 게시해야 실시간 화면에 반영됩니다.
실시간 화면 ↗ 현황 화면 ↗

GitHub 게시 권한

토큰은 서버에 전송되지 않고 이 브라우저의 세션 저장소에만 보관되며, 탭을 닫으면 사라집니다. 게시 버튼을 누르면 이 토큰으로 GitHub API를 직접 호출해 leaderboard/published.json을 커밋합니다. 저장소에 대한 쓰기 권한(fine-grained 토큰이면 Contents: Read and write)이 있는 토큰이 필요합니다.

결과 JSON 직접 입력

채점 파이프라인이 푸시한 leaderboard/result/result.json을 자동으로 불러옵니다. 순위는 마지막 eval_n(가장 최근 회차)의 total 기준입니다. 저장소에 아직 올라가지 않은 결과는 이 칸에 그대로 붙여넣고 "이 내용 사용"을 누르면 미리보기가 바뀌고, 게시하면 그 내용이 저장됩니다. 팀 이름·팀원은 agents.json(appid 기준)에서 가져옵니다.

점수 공개 시간

게시해도 이 시각 전까지는 실시간 화면에 이전 점수가 그대로 보이고, 채점 대기 화면에 "HH:MM 새로운 점수 공개 예정"으로 이 시각이 표시됩니다. 이 시각이 되면 순위 변동·라이징 스타·다크호스 화면이 30분 동안 나온 뒤 현황 화면으로 돌아갑니다. GitHub Pages 반영에 1~2분 걸리니 공개 시각보다 최소 3분 먼저 게시하세요.
